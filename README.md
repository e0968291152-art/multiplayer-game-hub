# 計算機概論專題：多元在線遊戲平台 (Multiplayer Game Hub)

本專題依據「計算機概論專題大綱」完整實作，包含三大獨立副本（個人單機與多人聯機）、電腦出題與主持人、角色職業配置與 5 分鐘確認機制，以及三大陣營對抗模式（拔旗戰、生存戰、據點戰）。

---

## 🎮 三大副本架構與規則總覽

### 1. 副本一：海龜湯（限 1 人・個人單機）
- **進入動畫與規則確認**：進入副本後播放動畫展示規則，待玩家點擊「確認鍵」後開局。
- **電腦擔任出題者與回答者**：
  - 由電腦提出一個難以理解的事件（表面謎團）。
  - 玩家可在對話框向電腦提出任何問題縮小範圍。
  - **電腦出題者回答限制**：僅能以**「是（對）」**、**「不是（不對）」**或**「沒有關係（無關）」**作答。
- **分小節劇情片段解鎖**：每推理完一小節就播放下一段劇情片段，直到完整還原故事線。
- **求助按鍵（3 次提示）**：遇瓶頸時可點擊側邊求助按鍵領取關鍵提示。

---

### 2. 副本二：狼人殺（限 8人、9人、10人、12人・多人聯機）
- **規則介紹動畫與確認**：開局展示角色配置與流程動畫，全員點擊確認鍵後進入。
- **電腦擔任公正主持人**：隨機分發身份、掌控晝夜交替、白天發言順序與投票放逐。
- **精確人數角色分發**：
  - **8人**：2名狼人、3名平民、1名預言家、1名守衛、1名女巫
  - **9人**：3名狼人、3名平民、1名預言家、1名女巫、1名獵人
  - **10人**：2名狼人、1名狼王、3名平民、1名預言家、1名女巫、1名獵人、1名白癡
  - **12人**：3名小狼、1名狼王、4名平民、1名預言家、1名獵人、1名守衛、1名女巫
- **白天順序發言**：依照主持人指示順序，依次在右側對話欄打字輸入發言。
- **特殊技能與規則實作**：
  - **白癡**：白天公投被投出時翻牌免疫放逐，之後失去投票權。
  - **女巫**：解藥僅首夜能自救；同守同救依然死亡；毒殺對象無法開槍。
  - **狼王/獵人**：淘汰時可開槍帶走一人（狼王不翻牌）。
  - **狼人自爆**：白天可隨時翻牌自爆，強制直接進入黑夜！
  - **規則八**：若好人陣營四位神職人物在首日白晝同時淘汰，狼人陣營直接獲勝！

### 3. 副本三：陣營對抗戰（限 14人、12人、10人・紅藍對抗）
- **隨機分組與職業配置**：
  - 隨機分為紅藍兩隊，右側提供己方隊伍聊天欄用於職業分配溝通。
  - **【指揮】**：每隊**限 1 人**。戰略部署核心。
  - **【輔助】**：佔隊伍人數 **30% 以下（取整數）**（5人隊限1人、6人隊限1人、7人隊限2人），負責治療與利用資源。
  - **【打手】**：其餘隊員全為打手，以武力護衛指揮與輔助，爭取勝利。
- **英雄角色挑選與屬性技能**：
  - **指揮**：
    - 斯蓋（血量8000/速度600/攻擊100）：護盾5s(-40%傷)、速度強化3s(+20%速)、隱身4s
    - 歐希（血量10000/速度500/攻擊70）：定身敵人2s、速度強化2s(+30%速)、虛無2s(免疫傷害)
    - 福瑞斯（血量6800/速度650/攻擊200）：護盾5s(-50%傷)、擊退控制中斷技能、瞬移隊友身邊
  - **輔助**：
    - 塞恩（血量6000/速度800/攻擊90）：護盾3s(免傷35%)、治療(+20%滿血)、磁引控制(拉敵並免傷1s)
    - 科賽恩（血量5300/速度850/攻擊160）：持續治療3s(+10%滿血)、攻擊提升4s(+30%傷)、消減敵方增益
    - 探菌（血量11000/速度450/攻擊250）：速度增益3s(+25%速)、免疫控制2s、定身1s
  - **打手**：
    - 阿爾法（血量5000/速度1000/攻擊650）：攻擊爆發(+50%傷)、生命燃燒3s(扣200血每秒攻擊+30%)、速度增強2s(+30%速)
    - 貝塔（血量15000/速度400/攻擊490）：吸收反彈2s(吸90%彈20%)、指定攻擊增強3s(+30%傷)、變換形態(切換戰鬥形態)
    - 伽瑪（血量9000/速度650/攻擊570）：裂地巨斬(150%攻擊傷害)、旋風刃(範圍傷減速)、戰吼霸體護盾
- **5 分鐘確認機制**：選完角色後按 **Enter** 鍵確認，所有玩家按 Enter 後進入（確認時間不可超過5分鐘）。
- **三大對抗模式（隨機抽取與規則動畫公佈）**：
  - **【拔旗戰】**：地圖中央單一軍旗，限時20分鐘；全場瀰漫毒氣（初始5分鐘免疫），打手擊敗妖獸收集三種資源合成解藥免疫毒氣；率先拔旗或倒數完最近者獲勝！
  - **【生存戰】**：限時24分鐘，每8分鐘切換晝夜，以全隊平均生存時長判定勝負。白天資源為真且刷新妖獸；黑夜部分資源為妖獸偽裝，部分道具包為炸彈（觸碰即淘汰）！指揮淘汰全隊暴露3分鐘且平均生存-1.5分鐘；輔助淘汰全隊暴露1分鐘。
  - **【據點戰】**：隨機5~7個據點，每5分鐘變換位置。找到據點按下計時按鈕開始3分鐘倒數，未被搶奪則標記成功。敵方可以武力搶奪（淘汰3名打手 / 殲滅守點人員 / 淘汰1名輔助或指揮），重置3分鐘倒數！
- **右側指揮欄**：戰鬥全程設有右側指揮欄供本隊隊員打字交流戰術。

## 🏛️ 大廳狀態與獨立副本機制

1. **大廳狀態字串規範**：
   - `副本二（尚未開啟）`
   - `副本二（正在招募中，目前為__人）`
   - `副本二（目前已有2－1副本進行中，可開啟2－2）`
2. **獨立遊戲不可中途加入**：遊戲一旦啟動，該副本即轉為獨立對局，新玩家僅能開啟新副本。
3. **隊長開始權限與上限限制**：隊伍人數達到限定要求時，開副本隊長介面出現「進入遊戲」按鈕；人數達上限則關閉加入。
